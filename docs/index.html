Model Architecture Specifications

• Multimodal Retrieval: 512-dimensional CLIP (clip-vit-base-patch32) mean-pooled restaurant profile vectors with cosine similarity matching.

• Personalized Recommendations: 4-layer Mixture Density Network (MDN) with batch normalization, trained on Yelp/Michelin user rating distributions. Outputs a Mixture of 3 Laplace distributions with uncertainty quantification (Highest Density Region).

• Aspect-Based Sentiment Analysis: Fine-grained review sentiment scored across Food Quality, Service, Ambiance, Value, and Wait Time using DistilBERT.

• Client-side Deployment: 100% static client-side execution hosted on GitHub Pages with zero server latency or cold starts.
